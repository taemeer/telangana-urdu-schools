# Telangana Urdu Medium Schools Directory

Interactive directory of all 177 distinct Urdu-medium high schools across Telangana, based on the Telangana School Education Department report supplied through the recipient organization. Primary and upper-primary schools are outside this dataset.

## GitHub Pages URLs
- English: `https://taemeer.github.io/telangana-urdu-schools/?lang=en`
- Urdu + English: `https://taemeer.github.io/telangana-urdu-schools/?lang=ur`

## Files
- `index.html` — application shell
- `css/style.css` — responsive layout and scrollable result table
- `js/app.js` — District and Comparison filters
- `data/schools.js` — browser-ready bilingual dataset
- `data/schools.json` — reusable bilingual JSON dataset
- `CORRECTIONS.md` — audit trail and totals

District selection accepts one to three districts. Comparison provides Govt, ZP and Girls-school views. Urdu mode displays Urdu and English on two lines, with shared serial-number and PIN-code cells.
